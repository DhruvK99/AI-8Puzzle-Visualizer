Introduction to the 8-Puzzle Problem

The 8-Puzzle consists of a 3×3 frame containing eight numbered square tiles (1 through 8) and one blank position (represented as 0 or _).

Legal Movement Rule: Only the blank tile may move by swapping places with an orthogonally adjacent tile (Up, Down, Left, or Right). Diagonal moves, tile jumping, and row wrapping are strictly forbidden.

Uniform Cost Search (UCS): Expands the frontier node with the lowest accumulated path cost g(n) using a binary minimum-priority queue. With unit step cost (c = 1 per move), UCS is both complete and optimal.

Terminology & Measurement Definitions

  • Solution Moves (d): Number of legal blank-tile transitions from the Initial State to the Goal State along the optimal path (d + 1 boards total).
  • Nodes Generated: Total unique states created and inserted into the priority-queue frontier during search (including the initial root state).
  • Nodes Expanded / Explored States: States popped from the minimum-priority queue whose legal successors were evaluated (or goal-tested upon removal).
  • Approximate Memory Usage: Calculated from live count of stored node records, priority-queue entries, and closed-set keys.

Algorithm Information & Theoretical Reference

Detailed specification of Uniform Cost Search (implemented) and reference documentation for uninformed and informed search strategies.

Implemented Algorithm: #5 Uniform Cost Search (UCS)

Description: Uniform Cost Search (UCS) is an uninformed best-first graph search algorithm that expands nodes in increasing order of accumulated path cost g(n) from the root state.

Working Principle & Priority Queue Behaviour:

  1. Initialize the frontier priority queue (binary min-heap) with the Initial State at path cost g(n0) = 0.
  2. Pop the node n with the lowest path cost g(n) from the priority queue.
  3. Perform the goal test upon removal from the priority queue. If n matches the Goal State, reconstruct the optimal path via parent pointers.
  4. Otherwise, place n in the Explored (Closed) set and generate all legal orthogonal blank-tile successors n'.
  5. For each successor n' with cost g(n') = g(n) + c(n, n') (where c = 1 per move in the standard 8-puzzle), insert n' into the min-heap if unexplored, or relax/update its parent pointer if a strictly cheaper path is discovered.
Evaluation / Cost Function f(n) = g(n), where g(n) is the exact cumulative step cost from the initial state. UCS uses no heuristic (h(n) = 0).
Completeness Complete (provided every step cost c(n, n') ≥ ε > 0 and the state space is finite or a solution exists).
Optimality Optimal — Because nodes are expanded in non-decreasing order of g(n) and goal testing occurs upon priority-queue removal, the first goal node expanded is guaranteed to have minimum total path cost.
Time Complexity O(b1 + ⌊C* / ε⌋), where b is the branching factor (b ∈ {2, 3, 4}, average ≈ 2.67), C* is the optimal solution cost, and ε = 1. With unit step costs, this simplifies to O(bd).
Space Complexity O(b1 + ⌊C* / ε⌋) = O(bd), as all frontier and explored states are retained in memory.
Advantages Guarantees minimum-cost solutions even when step costs vary; never gets trapped in infinite cycles when implemented as a graph search.
Limitations Explores uniformly in all directions without domain heuristics, consuming significant memory (O(bd)) on deep puzzle instances.
